# 과거 원문과 조사 기록

이 폴더는 출처 확인용이다. 현재 구현 기준은 [정본 안내](../README.md)와 [decisions.csv](../decisions.csv), 기능별 `상세명세`다. 원래 파일별 현재 위치는 [source-map.csv](../source-map.csv)에 있다.

- `baseline/`: 통합 전 승인 범위·D 결정·구조/로드맵·상세 계약·코드 분석·연구와 임시 정리 비교 메모.
- `2026-09-18-follow-up/`: Q-001~Q-021의 질문/사용자 답변/조사, P-001 원문과 P-002 조사 종합, 당시 진행 목록.

문서 본문과 질문·사용자 답변 원문을 보존하고 이동에 필요한 상대 링크만 고쳤다. 각 기록의 상단 표지는 현재 정본을 안내한다. 과거 파일의 ‘현재’·‘미정’·‘다음 세션 반영’·추천안·기능 개수는 당시 상태다. 현재 결정으로 다시 채택하거나 구현 요구로 추가하지 않는다. 특히 P-002와 임시 정리 비교 메모의 모든 기법을 사용자가 선택한 것은 아니다.

최초 [00-original-flow.md](../00-original-flow.md)는 기존 위치에서 바이트 그대로 유지했다. CSV의 기존 ID는 현재 정본에 그대로 유지하며 이전 CSV 내용은 Git 이력에서 확인할 수 있다.
