# Q12. 모델 배정과 다른 CLI로 넘기기

- 질문일: 2026-10-07
- 관련: [session-context.md](../session-context.md)의 "아직 묻지 않은 질문"(Model routing), [Q05](q05-accounts.md), [원래 구상](../00-original-flow.md) 0·1번
- 기록 원칙: 사용자 답변은 받은 그대로 적는다. 아래 "요약"은 찾아보기 편하도록 붙인 것이며, 내용이 다르면 답변 원문이 우선한다.

## 질문 (사용자에게 보낸 내용)

[Q11](q11-launcher-topology.md)과 같은 메시지에서 물었다. 인터뷰에서 아직 묻지 않은 6가지를 이번 정본 재작성에서 어떻게 다룰지 정해 달라는 질문이었다.

- 항목:
  - 모델 배정, 그리고 한 CLI가 한도에 걸렸을 때 다른 CLI로 넘길지
  - 작은 유지보수 요청의 승인 범위(OD-4)
  - 작업 계약을 어디에 둘지(OD-5)
  - 두 공급자의 조사를 합칠 범위(OD-6)
  - 병렬 실행(OD-8)
  - Codex 오케스트레이터가 한국어 글을 쓰는 방법
- 선택지:
  - **기본값으로 쓰고 나중에 인터뷰 (추천)** 정본은 지금 끝까지 쓴다. 6가지는 AI 기본값으로 채우고 '미결'로 표시한다. 정본을 다 쓴 뒤 하나씩 조사해서 여쭙고(Q11부터 기록), 답을 정본에 반영한다.
  - **먼저 인터뷰** 정본을 쓰기 전에 6가지를 하나씩 조사해서 여쭙고 interview/q11부터 기록한다. 다 정한 뒤 정본을 쓴다.
  - **기본값을 확정으로** AI 기본값을 정한 것으로 보고 정본을 쓴다. 따로 묻지 않는다.

## 사용자 답변 (2026-10-07, 원문 그대로)

선택지를 고르지 않고 직접 썼다.

```text
모델 배정은 프로젝트에 .barrel 폴더 내에 json 이나 config 파일로 설정할 수 있게 해줘. 팀원끼리 공유하거나 수정 가능하게. 그리고 다른 CLI 로 넘기는건 그냥 하라고 했잖아. PC에서 사용 가능한 CLI 다 활용하라고. 이 PC에도 config 폴더가 claude-wook 이랑 기본 claude 2개 있잖아. 그런거 다 활용하라고. 이거 말고 다른 부분들 인터뷰 진행하자.
```

## 요약 (원문이 우선)

- 모델 배정은 프로젝트의 `.barrel` 폴더 안에 JSON이나 설정 파일로 둔다. 팀원끼리 공유하고 고칠 수 있어야 한다.
- 다른 CLI로 넘기는 것은 이미 하라고 한 일이다. PC에서 쓸 수 있는 CLI를 모두 쓴다.
- 이 PC의 Claude 설정 폴더 두 개(`claude-wook`, 기본 `claude`)처럼 등록된 것은 모두 쓴다.
- 나머지 항목은 인터뷰로 정한다.

## 이 답에 따른 정리 (AI 분석, 원문이 우선)

- **다른 CLI로 넘기기:** 사용자는 이 항목을 이미 정한 것으로 본다. 다시 묻지 않는다.
  - [Q05](q05-accounts.md) 답: "1번째 계정을 못쓰게 되면 2번째 계정을 사용하는건 전혀 문제가 없어."
  - 원래 구상 0·1번: PC의 CLI를 섞어 쓰고, 계정별 폴더로 구독을 최대한 활용한다.
- **이 PC에서 확인한 것(2026-10-07):**
  - Claude 설정 폴더 `~/.claude`, `~/.claude-wook`
  - Codex 홈 `~/.codex` 하나
  - Claude Code 2.1.292, codex-cli 0.155.1, uv 0.11.19
  - Python 3.13(`/opt/anaconda3/bin/python3.13`). 시스템 `python3`은 3.9다.
- **설정 파일 형식:** JSON(`.barrel/config.json`)으로 정했다. AI가 정한 세부다. 이유는 셋이다.
  - 사용자가 먼저 말한 형식이다.
  - unit loop 설정도 JSON이다.
  - Slack 지시로 배정을 바꿀 때 Barrel이 표준 라이브러리만으로 파일을 안전하게 다시 쓸 수 있다.
- **나머지 항목:** [Q13](q13-depth-by-impact.md)부터 [Q16](q16-engines-and-verification.md)까지에서 물었다. 설정 파일의 모양(역할을 난이도 등급에 잇고, 등급마다 엔진 목록을 두는 것)은 Q16 답을 따랐다.
