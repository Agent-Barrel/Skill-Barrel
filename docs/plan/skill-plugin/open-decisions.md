## OD-1 to OD-10 from the 2026-09-29 draft

All ten are settled. The draft's text is archived in [docs/archive/skill-plugin-2026-09-29/open-decisions.md](../../archive/skill-plugin-2026-09-29/open-decisions.md).

| ID | Topic | Status | Decided by |

<a id="not-carried"></a>
## Not carried into this version

These are user decisions from the archived app plan that this design does not include. They are listed so the user can bring any of them back.

| Archived decision | Why it is not in this version |
| --- | --- |
| **Q-014, Q-015: one project spanning several repos, with a separate docs repo for shared planning** | Q07 and Q15 put memory and task files in "the target repo", one repo. Several repos would need a project-level `.barrel/` outside any one repo, and lanes per repo. That is a larger design than the interview covered |
| **D-007, D-030: preferences shared across projects, kept outside any repo; verified successes accumulated** | Q07 chose memory in the repo and turned down a PC-local folder. A preference the user states becomes a decision unit in the project it was stated in |
| Q-009: cancelling a job, with keep or discard for its unmerged changes | Barrel stops and resumes instead (Q10-2 chose option A; option C, which ended the run, was not chosen). A request given to a stopped run waits for the resume |
| D-031, in part: a configured default answer for "apply now or from the next task" | The cascade asks each time ([workflow.md](workflow.md#cascade)). A default can be added later |
| D-047, in part: changing the sleep policy from Slack | The policy is set with `barrel settings sleep` on the Mac. A Slack word for it can be added later |
| D-010: three approval bundles | Replaced by the intent review and the stack confirmation (Q01, Q06, Q13) |
| RTE-004/005: roles by provider | Replaced by Q16 |
